
# 🚀 AI Agent for High-Impact Resume Generation

> **"Accomplished [X] as measured by [Y], by doing [Z]"**

This repository contains the **Antigravity Skill** configuration for an AI Agent designed to automate the creation of high-impact, ATS-optimized resumes using the XYZ strategy.

## 📂 Repository Structure

```
/Resume_Agent
  /.agent
    /skills/resume_generation  # The "Brain" - Skill definition and prompts
  /resources
    resume.cls                 # The LaTeX class file for formatting
    master_resume_template.tex # The blank LaTeX template
  README.md                    # This file
```

## 🧠 How It Works

1.  **The Skill (`SKILL.md`)**: Defines the logic for the agent. It instructs the AI to:
    *   Extract keywords from Job Descriptions (JDs).
    *   Analyze your background context.
    *   Rewrite bullet points using the **XYZ Strategy** (Action, Metric, Result).
    *   Output LaTeX code.
2.  **The Context**: You provide a `career_profile.md` with your raw experience.
3.  **The Output**: The agent generates a `.tex` file that you can upload to Overleaf for a perfect PDF.

## 🛠️ Usage

1.  **Install Antigravity** (or use with your preferred AI agent framework).
2.  **Import the Skill**: Point the agent to the `.agent/skills/resume_generation` folder.
3.  **Provide Context**: Create a folder for yourself (e.g., `MyName/Directory`) and add your `career_profile.md`.
4.  **Run the Agent**:
    > "Help me tailor my resume for this [Paste JD] using my [Link to Profile]."

## 📄 The XYZ Strategy

Every bullet point generated by this agent follows the formula:
> **Accomplished [X] as measured by [Y], by doing [Z]**

*   **X**: Impact/Result
*   **Y**: Metric/Quantification
*   **Z**: Action/Methodology
