# Resume Generation Rules & Standards

This document defines the strict requirements for all resume variants generated by the Resume Agent. Adherence to these rules is mandatory to ensure professional quality and ATS optimization.

## 1. Contact Information
- **Zip Codes**: Strictly **FORBIDDEN**. Locations should be formatted as `City, State, Country` (e.g., `Dallas, Texas, USA`).
- **Location Alignment**: All role-specific resumes must be synchronized with the `master_context.yaml` source of truth.

## 2. Design & Typography (High-Fidelity V2.0)
- **Primary Font**: **Charter** (Serif).
- **Font Size**: **9pt** for the body to maximize information density while maintaining legibility.
- **Compiler**: Must be compatible with **Tectonic**. Avoid PDF-engine specific commands like `\pdfgentounicode=1` unless guarded.
- **Margins**: Narrow margins (approx. 0.5in left/right, 0.25in top) to ensure content fits on one page.

## 3. Content Engineering (XYZ Strategy)
- **The 2-Line Rule**: Every bullet point must be between **190-230 characters** to ensure it occupies exactly two lines of visual space.
- **Metric Bolding**: Use `\textbf{}` for all quantifiable metrics (percentages, dollar amounts, headcounts) and key technologies.
- **XYZ Formula**: Accomplished [X] as measured by [Y], by doing [Z].

## 4. Data Integrity & Verification
- **Audit Requirement**: After every generation, the `.tex` and `.pdf` files must be audited against the YAML source to ensure no sections (Certifications, Projects, etc.) are rendered empty or missing.
- **Flexible Schema**: The template is designed to handle both simple lists (`[ "Item A" ]`) and object lists (`[ { "name": "Item A" } ]`) for maximum flexibility.
- **Master Synchronization**: Never edit the `.tex` file directly. All changes must be made in the YAML or Template.

## 5. Operational Requirements
- **Single Source of Truth**: Biomarker data (dates, roles, locations) must be edited in `master_context.yaml` first.
- **Validation**: Every generation must pass the `generate_resume.py` validation check for forbidden words and bullet length.
- **Inventory**: The `resume_inventory.yaml` must be updated whenever a new role or path is created.
